Résumé du projet

Tacticook est un Roguelike Tactical-RPG mobile développé sous Unity. L'objectif était de créer un jeu fun et original sur mobile, dans le but de pouvoir si l'on a l'envie par la suite de le présenté a un éditeur.

Mon rôle

J’ai surtout travaillé sur les programmes secondaire (système de sauvegarde, système de dialogue et différents outils de production), et sur le playtest, la recherche de bug et leur correction.

Technologie testé

  • Sauvegarde Json
  • Création de tool

Fonctionnalités clés

Un système de sauvegarde générique pour enregistré l'inventaire du joueur et la carte généré procéduralement. Il y a aussi un xor pour crypter et décrypter les sauvegardes avec une clé pour empêcher un minimum la triche.

Save Function est un outil pour gérer les données de sauvegarde rapidement. On peut ouvrir l'emplacement de sauvegarde ou supprimer toutes les données en un seul clic.

Lien : Save Function

Dialog Maker est un outil pour convertir des fichier excel en scriptable object qu'on peut ensuite mettre dans un autre script pour les afficher. On peut aussi faire en sorte qu'il y ai quelques animation comme du shake sur le text etc...

Lien : Save Function

Ignore Folder est un outil pour naviquer plus rapidement dans les projet unity. Comme le nom l'indique il permet d'ignorer les dossier, quand tu clic sur l'un deux l'inspecteur ne perdra pas la référence précédente.

Lien : Save Function
